# Business Performance Intelligence Platform

BPIP is an advisor-led business performance assessment and intelligence workspace. The initial release supports a private advisory workflow, with an architecture intended to support multi-tenant SaaS and client collaboration in later phases.

## Product principles

- Evidence before conclusions: distinguish verified facts, owner perspectives, advisor hypotheses, and validated findings.
- Deterministic calculations: financial formulas and scores are calculated by tested application logic, not generated by AI.
- Human review: AI can assist with synthesis and recommendations, while the advisor validates findings.
- Tenant isolation: client and engagement data must be protected by organization-level authorization.

## Current status

Early advisor-workspace alpha. Authentication, authorization, data access controls, and assessment workflows are under active development. Do not use with real confidential client data until the security milestones are complete.
